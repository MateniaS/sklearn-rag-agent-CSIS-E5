1. Εισαγωγή.
Η παρούσα εργασία αφορά την ανάπτυξη ενός Agentic Retrieval-Augmented Generation συστήματος για την υποστήριξη χρηστών που αναζητούν πληροφορίες στο documentation του scikit-learn. Το σύστημα θα μπορεί να απαντά σε ερωτήσεις σχετικές με supervised machine learning workflows, όπως preprocessing, pipelines, classification models, evaluation metrics, cross-validation και hyperparameter tuning.


2. Στόχος του συστήματος.
Στόχος του συστήματος είναι να βοηθά αρχάριους και μεσαίου επιπέδου χρήστες της Python και της μηχανικής μάθησης να βρίσκουν τεκμηριωμένες απαντήσεις βασισμένες στο επίσημο scikit-learn documentation. Το σύστημα δεν βασίζεται μόνο στις γενικές γνώσεις ενός LLM, αλλά ανακτά σχετικά αποσπάσματα από το corpus και παράγει απαντήσεις grounded στο διαθέσιμο context.


3. Corpus και θεματικό πεδίο.
Το corpus της εργασίας θα αποτελείται από επιλεγμένες σελίδες του επίσημου scikit-learn documentation. Το θεματικό πεδίο περιορίζεται σε supervised classification workflows και περιλαμβάνει ενότητες σχετικές με preprocessing, pipelines, Logistic Regression, Random Forest, model evaluation metrics, cross-validation και hyperparameter tuning.

3.2 Τύποι ερωτημάτων που υποστηρίζει το corpus.
Το corpus υποστηρίζει τουλάχιστον τρεις βασικούς τύπους ερωτημάτων:


1. Conceptual questions: ερωτήσεις κατανόησης εννοιών, όπως τι είναι το feature scaling, τι σημαίνει cross-validation ή ποια είναι η διαφορά precision και recall.


2. Procedural / how-to questions: ερωτήσεις που ζητούν πρακτικά βήματα, όπως πώς δημιουργείται ένα Pipeline με StandardScaler και LogisticRegression ή πώς χρησιμοποιείται το GridSearchCV.


3. Decision-support questions: ερωτήσεις που βοηθούν τον χρήστη να επιλέξει κατάλληλη μέθοδο ή metric, όπως πότε είναι προτιμότερο το F1-score αντί για accuracy ή πότε μπορεί να χρησιμοποιηθεί Random Forest αντί για Logistic Regression.

04 report notes
Ημερομηνία: 19/05/2026


Αρχική επιλογή θέματος:
Το σύστημα θα είναι ένας Agentic RAG agent για το επίσημο documentation του scikit-learn.


Στόχος:
Να απαντά σε ερωτήσεις χρηστών σχετικά με supervised machine learning workflows, όπως preprocessing, pipelines, classification models, evaluation metrics, cross-validation και hyperparameter tuning.


Corpus:
Το corpus θα βασιστεί σε επιλεγμένες σελίδες του επίσημου scikit-learn documentation.


Γιατί επιλέχθηκε:
Το scikit-learn documentation είναι κατάλληλο corpus γιατί έχει αρκετό τεχνικό βάθος, σαφή δομή και υποστηρίζει διαφορετικούς τύπους ερωτήσεων: conceptual, procedural και decision-support.


Corpus sources:


Το corpus αποτελείται από 10 επιλεγμένες σελίδες του επίσημου scikit-learn documentation. Οι πηγές επιλέχθηκαν επειδή καλύπτουν ένα πλήρες supervised classification workflow: εισαγωγή στο scikit-learn, preprocessing, pipelines, train/test split, cross-validation, hyperparameter tuning, evaluation metrics, Logistic Regression και Random Forest.


Οι πηγές οργανώθηκαν σε πίνακα με doc_id, title, topic, url και reason_selected, ώστε κάθε document και κάθε μελλοντικό chunk να μπορεί να συνδεθεί με την αρχική του πηγή.


Ingestion plan:


Για το corpus θα χρησιμοποιηθούν δύο διαφορετικές στρατηγικές ingestion.


Η πρώτη στρατηγική, v1_fixed, θα βασίζεται σε fixed-size chunking. Σε αυτή την εκδοχή, το κείμενο κάθε σελίδας θα χωρίζεται σε chunks συγκεκριμένου μεγέθους με overlap, ώστε να δημιουργηθεί μια απλή baseline εκδοχή του RAG pipeline.


Η δεύτερη στρατηγική, v2_structured, θα βασίζεται σε structured ή section-based chunking. Σε αυτή την εκδοχή, το κείμενο θα χωρίζεται με βάση τη λογική δομή των documentation pages, όπως headings και sections, ώστε τα chunks να διατηρούν καλύτερα το νόημά τους.


Οι δύο στρατηγικές θα συγκριθούν αργότερα με βάση τα retrieval και evaluation αποτελέσματα.
